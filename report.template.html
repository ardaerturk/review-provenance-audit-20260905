Inspect the import

Three deliberate boundaries

  1. Identity before similarity. Only identical records with the same source and source ID collapse automatically.
  2. A branch is a separate clinic. An ambiguous brand name waits for an editor; a known source clinic ID can resolve it.
  3. Provenance is not verification. Every retained review still needs editorial review. No procedure is marked verified.

About this sample

Every clinic, source URL and statement here is fictional. The .example links show the provenance shape and are not live sources.

English translations are illustrative drafts. There is no live translation model or scraper in this prototype.

All processing is local and deterministic. The page sends no review data to a service.
